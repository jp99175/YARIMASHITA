# YARIMASHITA

Trois mini-applications de jet de dés, autonomes (aucune dépendance, aucun serveur).

- `dice.html` : Dés 1, D100 = 2 × D10
- `dice2.html` : Dés 2, panneaux de commande, écran à 16 segments
- `dice3.html` : Dés 3, plaques brun-taupe, écran ambre

Reprises du dépôt AMGT4CEM (`src/dice`, `src/dice2`, `src/dice3`). Pages servies par GitHub Pages depuis la racine de `main`.
